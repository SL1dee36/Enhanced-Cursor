# EnhancedCursor

EnhancedCursor — это лёгкая, высокопроизводительная программа для Windows, превращающая курсор мыши в органическую анимированную каплю с физически реалистичным флюидным хвостиком (или стильный кружок iPadOS). Он отображается поверх всех окон, плавно вытягивается и изгибается в зависимости от скорости и траектории движений руки, подхватывает системный акцентный цвет Windows и красиво реагирует на клики.

Программа делает работу за компьютером визуально приятной и тактильной, а также незаменима при записи обучающих видео, презентациях и стримах.

---

### Основные возможности

* **Физическая флюидная капля (Fluid Teardrop)**: капля состоит из многозвенного жидкостного хребта с поверхностным натяжением. При ускорении она вытягивается в аэродинамическую каплю, при поворотах хвостик изгибается по дуге траектории, а при остановке пружинит с приятным желейным отскоком (Jelly Bounce).
* **Отрисовка поверх Windows или замена курсора**: можно выбрать как режим ауры/шлейфа за обычной стрелкой, так и режим **полной замены системного курсора** (стрелка Windows автоматически скрывается, и остаётся только капля).
* **Адаптивные системные цвета**: автоматическое чтение акцентного цвета Windows 10/11 и адаптация каймы под тёмную/светлую тему на лету.
* **Zero-Lag движок**: подключение системного мультимедийного таймера `1 мс` (`winmm.timeBeginPeriod`), частота обновления ~165 FPS и независимая $\Delta t$-интеграция без пропусков кадров и джиттера.
* **Всплеск капель при клике (Liquid Splash)**: при нажатии от капли разлетаются микро-брызги, сопровождаемые расходящейся волной (Ripple).
* **Раздельный отклик для ЛКМ и ПКМ**: визуальное разделение кликов левой и правой кнопкой мыши разными цветами.
* **Shake to Find (как в macOS)**: быстрое покачивание мыши временно увеличивает каплю в 2.5 раза с яркой подсветкой, чтобы мгновенно найти курсор на 2K/4K или нескольких мониторах.
* **Быстрое переключение пресетов из трея**: «Системный акцент (Капля)», «Жидкая ртуть (Mercury)», «Неоновая комета (Cyberpunk)», «Капля воды (Water Drop)», «iPad Classic» и др.
* **Умное скрытие**: плавное угасание при бездействии, скрытие при наборе текста (I-Beam) и автоматическая пауза в полноэкранных играх.
* **Отрисовка поверх системных окон и модалок**: надёжное удержание Z-order поверх стандартных и системных диалоговых окон Windows (`#32770`, `Win+R`, MessageBox, проводник, диалоги открытия/сохранения файлов).
* **Поддержка прав Администратора**: возможность запуска с повышенными привилегиями одной кнопкой из настроек или трея для отображения поверх Диспетчера задач и окон с повышенным уровнем целостности (UAC/High Integrity).
* **Горячая клавиша**: быстрое включение/выключение сочетанием Ctrl + Alt + H в любой момент.

### Как пользоваться

1. Запустите `ecur.exe` (или запустите исходник через Python).
2. В системном трее (в правом нижнем углу экрана) появится значок программы.
3. Кликните по значку, чтобы открыть окно настроек:
   * Здесь можно настроить размер кружка, толщину границы и размер внешнего контура.
   * Выбрать любые цвета и прозрачность для каждого элемента.
   * Настроить скорость перемещения и длительность анимации при нажатии.
   * В правой части окна находится окно предпросмотра, масштаб которого можно менять колёсиком мыши или ползунком внизу.
4. Нажмите «Save», чтобы сохранить изменения.
5. Чтобы быстро сменить стиль, щёлкните по значку в трее правой кнопкой мыши и перейдите в подменю «Presets».
6. Чтобы закрыть программу, нажмите «Exit» в меню трея.

---

### Горячие клавиши и управление

* Ctrl + Alt + H — быстро включить или выключить подсветку.
* Клик по значку в трее — открыть настройки.
* Правый клик по значку в трее — меню выбора пресетов, открытие настроек, просмотр журнала и выход.
* Колёсико мыши в окне настроек — зум окна предпросмотра.

---

### Системные требования

* Операционная система: Windows 10 или Windows 11 (работает и на Windows 7 / 8).
* Для запуска из исходников: Python 3.10 или новее.

### Запуск из исходного кода

Если вы хотите запускать или модифицировать проект напрямую:

1. Склонируйте репозиторий:
```bash
git clone https://github.com/sl1dee36/Enhanced-Cursor.git
cd Enhanced-Cursor
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python ecur.py
```

---

### Сборка exe-файла

Чтобы собрать полностью автономный файл `ecur.exe` со своей иконкой:

Просто запустите скрипт сборки:
```cmd
build.bat
```

Или выполните команду сборщика вручную:
```cmd
pyinstaller --clean ecur.spec
```

Готовый файл появится в папке `dist/ecur.exe`. Ему не требуется установленный Python — его можно переносить на любой другой компьютер с Windows.
